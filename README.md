# لوحة العملاء — Zarqa Leads

لوحة لإدارة العملاء المحتملين (مفروشات، مطاعم، عيادات...) بالزرقاء وعمان: جرد كامل، مسار متابعة، واتساب بكبسة، ومساعد Gemini بيحل مشاكل البيع. شغّالة كموقع (Render) وبتتحوّل لتطبيق أندرويد من الرابط، وكل الأجهزة بتتزامن مع بعض.

## شو جواتها
| | |
|---|---|
| `server.js` | السيرفر: كلمة سر، مزامنة، تمرير طلبات Gemini (المفتاح ما بيطلع للمتصفح) |
| `server/leads.json` | 785 عميل (منهم 667 مفروشات: 569 عمان، 80 الزرقاء، 18 الرصيفة) |
| `public/` | الواجهة (لوحة التحكم، العملاء، المتابعة، الجرد، المساعد، الإعدادات) |
| `public/merge.js` | منطق دمج البيانات بين الأجهزة |
| `render.yaml` | إعداد Render بكبسة وحدة |
| `brand/` | اللوقو (SVG + PNG) بأربع أفكار |
| `exports/` | ملف الإكسل الأصلي + شيت الليدز الجديدة |

## التشغيل على جهازك
```bash
npm install
cp .env.example .env   # وحط APP_PASSWORD و GEMINI_API_KEY
npm start              # http://localhost:3000
```

## النشر على Render
1. ارفع الريبو على GitHub (يفضّل **Private**).
2. بـ Render: **New → Blueprint** → اختار الريبو → Render بيقرأ `render.yaml`.
3. بيسألك عن:
   - `APP_PASSWORD`: كلمة سر الدخول للوحة (اختار وحدة قوية).
   - `HR_PASSWORD`: كلمة سر حساب الـ HR (عرض التقارير بس).
   - `GEMINI_API_KEY`: مفتاح Gemini.
4. **Apply**. بعد دقيقتين بيعطيك رابط زي `https://zarqa-leads.onrender.com`.

> الخطة المجانية بتنام بعد 15 دقيقة بدون استخدام، وأول فتحة بعدها بتاخذ حوالي دقيقة.

### التخزين
- **افتراضياً**: السيرفر بيحفظ بملف، وكل جهاز معه نسخة كاملة. على الخطة المجانية الملف بينمسح لما السيرفر يعيد تشغيل، بس أول جهاز بيفتح اللوحة بعدها بيرجّع البيانات تلقائياً.
- **للتخزين الدائم**: اعمل قاعدة Postgres مجانية (مثلاً [Neon](https://neon.tech))، وحط رابطها بـ `DATABASE_URL` بـ Render → Environment.

## تطبيق الأندرويد (من الرابط)
اللوحة جاهزة كـ PWA (فيها manifest وأيقونات وكاش)، فبتتحوّل لـ APK بسهولة:
1. افتح [PWABuilder](https://www.pwabuilder.com) وحط رابط Render.
2. **Package for stores → Android** → نزّل الحزمة، وجواتها ملف APK جاهز للتثبيت.
3. للأيقونة استعمل `brand/png/logo-a-square-1024.png` (أو الفكرة اللي بتختارها).

أو أسرع: افتح الرابط بـ Chrome على الموبايل → ⋮ → **إضافة للشاشة الرئيسية** وبيصير زي التطبيق.

## حساب الـ HR
- بيدخل بنفس الرابط بكلمة سر `HR_PASSWORD`، وبيشوف **تقرير الإدارة** بس:
  - أداء كل موظف: تواصل، اتصالات، واتساب، صفقات، إيرادات.
  - الصفقات المغلقة، ومين لازم نتصل فيهم، وسجل التواصل الكامل، والعروض المفتوحة.
  - فلترة حسب الفترة والموظف، وتصدير Excel.
- ما بيقدر يعدّل ولا إشي، والسيرفر بيرفض أي تعديل منه.
- كل موظف بيكتب **اسمه** لما يسجّل دخول، وكل اتصال/رسالة/تغيير حالة بيتسجّل باسمه.

## الأمان
- مفتاح Gemini موجود بس بـ `.env` المحلي وبـ Render. **ما في أي مفتاح بالكود.**
- كل البيانات وطلبات Gemini محمية بكلمة السر.
